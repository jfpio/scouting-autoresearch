# Kolejka recenzji

Tu trafiają propozycje źródeł, aktywności, tłumaczeń i decyzji prawnych. Wpis nie jest
zatwierdzeniem. Pierwsze kierunki badawcze opisuje `config/research-queue.yaml`.

Rekordy `candidate-*.md` dokumentują etap `discover` dla jednej konkretnej edycji. Muszą
pozostać `rights-review`, używać metody dozwolonej w `config/source-registry.yaml`, wskazywać
dowody proweniencji i blokować pełny tekst, ilustracje, tłumaczenie oraz publikację do czasu
decyzji człowieka. Samo oznaczenie domeny publicznej przez kolekcję w jednej jurysdykcji nie
jest zatwierdzeniem dla projektu.
