# Zaakceptowane

Przeniesienie rekordu do tego katalogu wymaga decyzji człowieka zapisanej z datą, osobą
zatwierdzającą i dowodem albo jednoznacznego dopasowania zatwierdzonej przez człowieka
polityki kolekcji. W drugim przypadku rekord zapisuje `approvalPolicyId` i dowód spełnienia
jej warunku. Agent nie może tworzyć ani zatwierdzać własnej polityki.

Akceptacja może dotyczyć tylko części obiektu, na przykład oryginalnego tekstu bez skanów,
ilustracji i późniejszej redakcji. Rekord musi jawnie podać `approvedScope`, osobne flagi
kwalifikacji komponentów oraz wszystkie wyłączenia. Wyłączony komponent nie blokuje użycia
zakresu, który człowiek zatwierdził.
