# Taksonomia

V0 zachowuje źródłowe cechy prób i działy książek. Taksonomia V1 będzie dwujęzyczna,
wersjonowana i oddzieli źródłowe określenia od współczesnych kategorii redakcyjnych.
Synonimy służą wyszukiwaniu; nie mogą zmieniać treści źródłowej ani udawać danych z książki.

Istniejące pola `traitCategories` zaimportowane z wcześniejszego wydania cyfrowego są
zastanym mapowaniem redakcyjnym, a nie zatwierdzoną taksonomią V1. Pozostają materiałem
porównawczym do czasu opisania definicji, wersji, mapowań i ręcznej decyzji redakcyjnej.
