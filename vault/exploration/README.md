# Eksploracja

Ten katalog jest notatnikiem badawczym bazy wiedzy. Przechowuje propozycje, które mogą
wyniknąć podczas lektury źródeł, ale nie są jeszcze częścią zatwierdzonego modelu danych:

- `taxonomy/` — pomysły na kategorie i podkategorie cech, ich synonimy oraz granice,
- `activity-kinds/` — pomysły na rodzaje aktywności inne niż gra i próba,
- `filters/` — proponowane fasety wyszukiwania i ich granice, zanim trafią do modelu danych,
- `templates/` — szablon nowej propozycji.

Status `proposed` oznacza hipotezę redakcyjną. Agent może ją dopisać i zebrać przykłady,
ale nie może sam zmienić jej na `accepted` ani automatycznie przeklasyfikować korpusu.

Każda propozycja powinna docelowo zawierać:

1. jednoznaczną definicję po polsku i angielsku,
2. przykłady i kontrprzykłady wskazane identyfikatorami aktywności,
3. informację, czy etykieta pochodzi ze źródła, czy jest współczesnym ułatwieniem,
4. relację do istniejących kategorii,
5. decyzję człowieka wraz z datą i uzasadnieniem.
