## Treść źródłowa

Wszyscy stoją parami. Każda para zna swój numer. Kierownik wywołuje naprz. „6-ta para naprzód”. Gdy chcemy, aby wszyscy biegali kolejno zawsze wołamy: ostatnia para naprzód, ale to mniej ciekawe.
