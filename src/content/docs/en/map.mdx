# Semantic map of games

An exploratory similarity map of 199 historical games with a source filter and accessible list.

> **How to read the map:** nearby points have similar text according to the embeddings, but position is neither a category nor evidence of common historical origin. Category and participant-count filters will appear only after manual approval of the data model. The map does not publish unreviewed relation candidates.
