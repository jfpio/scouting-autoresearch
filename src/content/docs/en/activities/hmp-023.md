## Translated text

The Scoutmaster prepares a certain number of paper bags of various sizes and places in each one an object with a different scent, such as chopped onion, rose petals, leather, orange peels, and the like. The bags are arranged in a row, half a meter apart from one another, and the Scouts are instructed to smell each bag in turn for 5 seconds. Finally, each Scout has one minute to write down from memory the objects they recognized, in the order in which they were arranged.
