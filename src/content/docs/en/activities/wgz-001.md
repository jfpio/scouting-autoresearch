## Translated text

The group goes out to the adjacent room. The patrol leader places a small object (a lead soldier) in a visible spot. The Cubs return and begin searching. The first one to find it hides the object in the next game.

Several nails or nibs can be hidden. The Cub who finds the greatest number within the set time wins and starts the game anew by redistributing the nails in the group's absence.
