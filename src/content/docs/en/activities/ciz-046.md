## Translated text

A game that trains the power of observation and requires considerable skill in tracking. One or 2 patrols take part in it. Of the many ways to conduct this game, I will mention only 3 methods, according to which other variations can be arranged.

I. The Ariadne’s thread consists of clues written in short sentences using an agreed cipher. The first note is placed on a designated gate, telegraph pole, a certain company’s poster, etc., and reads, for example: »Go north and pay attention to the posters under the railway bridge.« There, the second note is found: »Go south to telegraph pole No. 22.« There should not be too many of these clues, and the points should not be too easily accessible. This method can be used to compete for a prize among several patrols, which are then sent out every 15 minutes. The winner is the one who reaches the treasure in the shortest time. Alternatively, a different task can be assigned to each patrol, e.g., for patrol A, the route: abcdef, and for patrol B, the route: acbedf. In this case, the clue notes will need to have 2 halves: under A will be the task for the first patrol, and under B for the second patrol.

II. The Ariadne’s thread is represented by colored wool or flannel patches attached to gates, fences, etc., every 3 meters, leading in a certain direction. When they end, a specified number of steps and a designated direction should lead to the treasure, usually represented by some letter. To prevent this from being merely a hare-and-hounds game or cotton-gathering, several false trails should be deliberately created, diverging from the main direction for a dozen or so meters and leading astray. All patches must, of course, be collected.

III. Each participant receives a description of a different route to the hidden treasure. For example: »Go to the spreading oak in locality NN., or to the crossroads NN., then take 300 steps north, and when you align with the tower NN., go west for 50 steps. From there, follow the path to the shrine, from which 10 steps to the left lies the treasure (a letter).« At the designated points, there should be patches or notes that scouts must collect as proof they did not shorten their route. The first to reach the treasure should not reveal they have arrived but should pretend to be diligently continuing the search.
