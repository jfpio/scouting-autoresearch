## Translated text

A game combined with a memory exercise, similar to "Neighbor." The patrol leader or troop leader arranges 10 sentences or sequences loose words so that the first row contains 3 words, each beginning with *j* (one), the second row contains 4 words, each beginning with *d* (two), the next row 5 words, each beginning with *t* (three), and so on up to 9. The game proceeds as follows: the patrol leader first recites the first row, after which everyone repeats it in turn; then the second row, and once everyone has repeated it in order, the 3-th row is given, and so on. Whoever fails to repeat a row in the correct order forfeits a token or steps out of the circle of players:

1. j. tomorrow, hag, groan. 2. d. courtier, rain, mockery, claw. 3. t. grass, rhythm, rod, wolfsbane, trumpet. 4. cz. to comb; to lurk, honor, human, ambush, crest. 5. p. carrion, to water, beauty, to knock, to spin, to bake, ravine. 6. sz. happiness, rat, wardrobe, awl, wide, rag, swindler, glass. 7. s. sickle, string, ergot, oat-grass, rock, sadness, quarrels, knot, leap. 8. o. fruit, insect, bran, perch, eye, weapon, fire, hound, garden, wasp. 9. dz. mullein, woodpecker, hollow, child, javelin, bell, jug, wilderness, wonder, spear, cannon.
