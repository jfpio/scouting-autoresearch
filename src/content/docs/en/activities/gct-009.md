## Translated text

After leaving the city, the instructor orders the participants to describe on sheets of paper, for example: a section of the path traveled, a street, an orchard observed during the march, a bridge, etc.

Evaluation takes place openly with the children's participation. A point is awarded for each correctly noticed detail. The highest number of points determines the winner. The game leader should discreetly note the details of the given object.
