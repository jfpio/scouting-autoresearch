## Translated text

The Scoutmaster marches with the patrol (in dispersed formation) to a foreign town or more challenging terrain, also unknown, using a cycling map (i.e., 1:750.000). He explains where they aim to reach, after which each Scout takes turns as the patrol guide (for 7 minutes if by bicycle, for 15 minutes if on foot). The guide must find the way using only the map; for skillful map reading, marks are awarded.
