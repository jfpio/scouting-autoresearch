## Translated text

The task is to mark a straight line in a specific direction, e.g., W–E. The first scout stands with a compass in hand, facing west. The second scout walks 30–50 paces in that direction according to the compass, and the third scout walks another few dozen paces, then aligns with the two previous scouts. The first scout then moves forward, positioning himself in line with the others, and so on. The line can be extended as needed, marking each abandoned position with a stick or stone.

The same method can be used to mark a line in the required direction at night using flashlights.
